# Expo SDK version

This project is pinned to Expo SDK 54 (to match the installed Expo Go app, version 54.0.8).
Docs: https://docs.expo.dev/versions/v54.0.0/

Do not upgrade `expo`, `react`, or `react-native` without also updating the Expo Go app on the test device, and re-running `npx expo-doctor` afterwards.
